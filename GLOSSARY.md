# Domain glossary

Единый словарь доменных терминов. Если что-то называется здесь одним словом — в коде, в БД, в API, в UI оно называется тем же словом. Это критично и для команды, и для LLM-агентов, генерирующих код.

| Термин (EN)        | Перевод            | Что означает                                                                       |
|--------------------|--------------------|------------------------------------------------------------------------------------|
| **User**           | Пользователь       | Любой авторизованный человек в системе. Имеет одну `role`.                          |
| **Role**           | Роль               | `student` \| `teacher` \| `admin`. Определяет доступы.                              |
| **Student**        | Ученик             | User с role=student. Бронирует и посещает уроки.                                   |
| **Teacher**        | Учитель            | User с role=teacher. Создаёт уроки, проводит видеозвонки.                          |
| **Admin**          | Администратор      | User с role=admin. Управляет школой и видит всех.                                  |
| **Lesson**         | Урок               | Запланированное занятие в конкретное время. Ведёт teacher, посещают students.       |
| **Booking**        | Бронирование       | Запись student'а на конкретный lesson.                                              |
| **Recording**      | Запись             | Видео урока, доступное после его завершения.                                       |
| **Notification**   | Уведомление        | Сообщение пользователю (lesson_created, booking_confirmed, …).                     |
| **VideoCall**      | Видеозвонок        | Активная Google Meet-сессия для lesson'а в момент его проведения.                  |
| **Channel**        | Канал              | Способ доставки notification: `telegram` \| `push` \| `email`.                     |
| **Level**          | Уровень            | CEFR уровень владения языком: `A1`–`C2`.                                            |
| **DomainEvent**    | Доменное событие   | In-process событие через EventBus: `lesson.created`, `booking.confirmed`, ...      |

## Запрещённые синонимы

| Не используй | Используй | Где                                |
|--------------|-----------|------------------------------------|
| Reservation  | Booking   | везде                              |
| Class        | Lesson    | везде (Class — это TS-keyword)     |
| Tutor        | Teacher   | везде                              |
| Pupil        | Student   | везде                              |
| Account      | User      | в коде; в UI допустимо для краткости |
| Course       | (пока нет такой сущности — обсуждать перед добавлением) |  |

## Когда добавлять термин

Когда понятие появляется в обсуждении и непонятно, как его звать:
1. Открой PR с обновлением `GLOSSARY.md`.
2. Получи апрув продакта.
3. Только после этого используй в коде.

Это дешевле, чем переименовывать сущность в БД через полгода.
