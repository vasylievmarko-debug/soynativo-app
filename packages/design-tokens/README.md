# @soynativo/design-tokens

**Платформа-агностичные** дизайн-токены: цвета, отступы, типографика, motion, тени, радиусы, breakpoints.

Без зависимостей. Используется и React Native (mobile), и в будущем — веб-админкой и любыми другими платформами. Дизайнеры работают в Figma → токены экспортируются сюда → код их потребляет.

## Принципы

1. **Один источник правды.** Все остальные пакеты импортируют отсюда.
2. **Никакой логики, только данные.** Чистые `as const`-объекты, чтобы TS вывел литералы.
3. **Семантика поверх примитивов.** Палитра живёт здесь как примитив; семантические имена (`background`, `text`, `primary`) собираются в темах конкретной платформы (см. `apps/mobile/src/shared/ui/theme/theme.ts`).
4. **Никаких magic numbers в коде приложения.** Если нужно значение, которого нет в токенах — добавь токен, не подставляй число.

## Содержимое

| Файл              | Что внутри                                          |
|-------------------|-----------------------------------------------------|
| `colors.ts`       | `palette` (brand 50–900, neutral 0–1000, semantic)  |
| `spacing.ts`      | 4-pt grid: `xs`(4) → `4xl`(64)                      |
| `typography.ts`   | `display`, `h1`–`h3`, `body`, `caption`, `button`, `overline` |
| `radius.ts`       | `sm`(4) → `2xl`(24), `full`(9999)                   |
| `motion.ts`       | `duration` (100–600ms), `easing` (Material-curves)  |
| `elevation.ts`    | RN shadows + Android `elevation` для `sm`–`xl`      |
| `breakpoints.ts`  | `phone`, `phablet`, `tablet`, `desktop`, `wide`     |

## Workflow «Figma → код»

1. Дизайнер обновляет токены в Figma (через плагин Tokens Studio или Figma Variables).
2. Экспорт в JSON, преобразование в TS-объекты этого пакета (script TBD).
3. PR с обновлёнными токенами проходит ревью.
4. CI прогоняет визуальные регрессионные тесты (в будущем — Chromatic/Percy).
